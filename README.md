# Agit Nihongo

Website belajar bahasa Jepang untuk pemula, berbahasa Indonesia.

🔗 **Buka website:** https://agitbayy.github.io/agit-nihongo/

## Isi

- **Hiragana & Katakana**: bagan 46 huruf dasar, contoh kata, dan suara
- **Kosakata**: salam, perkenalan, angka, dan makanan
- **Kanji**: 471 kanji level N5 dan N3, lengkap dengan bacaan On/Kun dan contoh kata
- **Kuis**: pilih materi dan jumlah soal, skor terbaik tersimpan

## Catatan

- Kemajuan belajar tersimpan di browser masing-masing pengguna.
- Daftar kanji N3 mengikuti kanjikana.com. Bacaan dan contoh kata dilengkapi manual, jadi bisa ada kesalahan.
